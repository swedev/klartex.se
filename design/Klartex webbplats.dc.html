Skicka strukturerad data, få ett färdigt dokument.

Kallelser, protokoll, fakturor och årsredovisningar som PDF.

Renderingen finns som ett öppet HTTP-API. Det här anropet fungerar som det står, utan installation och utan konto:

curl -X POST https://app.klartex.se/api/render \
  -H 'Content-Type: application/json' \
  -d '{"template":"faktura","data":{
        "invoice_number":"2026-001","date":"2026-03-01","due_date":"2026-03-31",
        "recipient":{"name":"Kundföretaget AB"},
        "lines":[{"description":"Konsultarbete","quantity":10,"unit":"tim",
                  "unit_price":1200,"vat_percent":25}]}}' \
  -o faktura.pdf

Två sätt att använda det

UTAN INSTALLATION

Rendera ett dokument nu

Anropa app.klartex.se/api som ovan. Ingenting att installera — servern har TeX-installationen. Det här är vägen för enstaka dokument och för agenter som fått i uppgift att producera en PDF.

EGEN DRIFT

Bygg in det i din tjänst

Installera paketet och kör renderingen i din egen miljö:

$ pip install klartex

Kräver Python ≥ 3.12 och en TeX-installation med XeLaTeX — flera gigabyte, oavsett plattform. På macOS: brew install --cask mactex. På Debian/Ubuntu:

$ sudo apt install texlive-xetex texlive-fonts-recommended \
    texlive-latex-extra texlive-latex-recommended \
    texlive-science texlive-plain-generic

Värt det när renderingen ska ligga i din egen drift, onödigt för ett enstaka dokument. Backenden bakom app.klartex.se/api är själv exakt det här fallet: den importerar klartex som bibliotek.

Scheman hämtas från API:t — ingenting behöver gissas eller hårdkodas:

Samma information finns i llms.txt, skriven för att läsas av AI-agenter.

Vad som är öppet

INGEN TOKEN

Rendering och schema-uppslagning är öppna och kräver ingen token. De är avsedda för att prova, för enstaka dokument och för sällananvändning, och renderingsanropen är takade per IP-adress.

Egen formgivning går också att skicka med per anrop via page_template i objektform, som tar typsnitt och sidfot direkt i datan och fungerar utan token.

KRÄVER TOKEN
403

latex-blocket skickar rå LaTeX vidare till kompilatorn och kräver en token — ett anonymt anrop med ett sådant block svarar 403 och pekar ut blocket.

401

Att registrera en egen sidmall — med logotyp, sidhuvud och sidfot som återanvänds mellan dokument — kräver en token, och POST /api/page-templates svarar 401 utan.

Konton är under utveckling och inte lanserade än.
